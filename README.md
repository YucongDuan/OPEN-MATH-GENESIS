# DIKWP-MESH8.1 OPEN-MATH GENESIS

Open-problem genome, native proof-genesis, and bidirectional closure system.

The package organizes 44 externally open mathematical problems into twelve D/I/K/W/P-derived proof genomes, validates finite semantic carriers, exports language-optional `.d81p` files, computes cross-problem neighbors, and builds an offline interactive atlas.

A `STRUCTURAL_PASS` validates declared interfaces only. It does not execute problem-specific mathematics and does not certify any open conjecture as a theorem.

Quick start:

```bash
pip install -e .
omg81 summary
omg81 show O01
omg81 validate examples/certificates/o01_open_bridge.json
```

Open `site/index.html` for the offline dashboard. Code is Apache-2.0 licensed.
